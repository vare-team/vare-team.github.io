Privacy Policy — Doctor Whooves

Last updated: November 23, 2026.

Vare provides Doctor Whooves (Discord bot username Whooves, application ID 531094088695414804) as a free, open-source moderation and utility bot. This policy explains which information the bot processes, why it processes it, and how to contact us about your data.

Information Collection and Use

The information processed depends on the commands used and the features enabled by server administrators:

  • Server settings: server IDs, feature settings, selected currency and configured log-channel IDs are stored to operate the bot.
  • Moderation records: warning records contain the user ID, server ID, moderator or bot ID, warning reason and record timestamps. Automatically generated profanity warnings use a generic violation reason. Moderators may supply their own warning reasons.
  • User progression: user IDs, experience, level and virtual currency balances are stored for the bot's progression and utility features. Experience may increase when a user sends a message.
  • Member information: names, nicknames, IDs, account creation and server join information are processed for configured join/leave logs and nickname moderation. The administrator command /correctall retrieves server members to identify nicknames requiring correction. The database does not maintain a complete copy of server membership.
  • Message content: new and edited messages are checked against a prohibited-word list when chat moderation is enabled. Available text from edited and deleted messages is used for the configured moderation logs. These features also process author and channel information. Message bodies are not routinely archived in our external database; edit/delete logs are posted within Discord. Message data may be held temporarily in the bot's memory while it operates.
  • Commands and utilities: command inputs, selected messages, images, avatars and links are processed as needed to provide the requested result. Voice-channel events are used for configured join, leave and move logs; the bot does not record voice audio.
  • Operational logs: command names, user identifiers, server/channel identifiers, interaction metadata and error information may be recorded to operate and troubleshoot the service.

Whooves does not require users' online status or activity/presence data for these features. Message content is not used to train machine learning or AI models.

Where Information Is Stored and Shared

Server configuration, warning records and user progression values are stored in our database outside Discord. Moderation logs are sent to the Discord channel configured by server administrators and can be viewed by people who have access to that channel. Operational notifications may also be sent through a configured Discord webhook.

The Unshorten message command sends the detected URL from the selected message to unshorten.me to resolve its destination. This happens when the command is invoked; it is not an automatic export of all messages. The service processes that URL under its own practices. Aggregate bot statistics, such as server and shard counts, are sent to Server Discord monitoring. The colour utility uses singlecolorimage.com to display an image for the requested colour.

We use this information to provide, maintain and troubleshoot the bot and to handle support and deletion requests. We do not sell user data or use message content for advertising.

Retention and Deletion

Stored configuration, warnings and progression records may remain for more than 30 days. The bot does not apply a universal automatic 30-day deletion period. Moderation warnings can be removed by authorised moderators using the bot's warning-removal command. Removing the bot from a server does not by itself guarantee immediate deletion of existing database records.

To request access to or deletion of your stored data, contact us using the details below and provide the relevant Discord user ID and, where applicable, server ID. We may ask for information needed to verify that the request concerns your data. We will review the request and explain any limitation that applies.

Logs already posted in Discord are separate from our database records. Their visibility and deletion are controlled through Discord and the permissions of the destination server. Contact the relevant server administrators about those messages; you can also contact us for assistance with bot-generated logs.

Controls and Security

Server administrators control the bot's moderation features and configured log channel. There is no individual opt-out switch that exempts a user from all message processing on a server where these features are enabled. Users can contact the server administrators about the server's configuration and contact us about stored records.

We restrict administrative access to stored data. No method of transmission or storage is completely secure. Do not include passwords, access tokens or other secrets in command inputs or support requests.

Changes to This Policy

We may update this policy as the service changes. Updates will be published on this page with a revised date.
